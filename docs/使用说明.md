## 1. 安装

### 系统要求

```
Android 8.0 及以上
存储空间 60MB
网络：能连上 api.deepseek.com
```

### 安装步骤

```
① 拿到 APK 文件（大肥鱼-独立版-vX.X.apk）
② 传到手机
③ 用文件管理器点开 → 允许安装未知来源
④ 返回桌面，找到「爱吃白饭的大肥鱼手机版」
```

**图标是一个蓝发鲸鱼女仆。**

### 关于权限

**不需要给任何权限。** 不用 GPS、不用通讯录、不用后台定位。

唯一会弹的是**通知权限**——只有用「定时提醒」时才会问。

## 2. 第一次使用

### 第一次打开会自动跳到设置页

```
┌──────────────────────────────┐
│  设置                         │
│                              │
│  DeepSeek API Key            │
│  ┌────────────────────────┐  │
│  │ sk-••••••••••••••••••  │  │
│  └────────────────────────┘  │
│                              │
│  她叫什么                     │
│  ┌────────────────────────┐  │
│  │ 小鲸                    │  │
│  └────────────────────────┘  │
│                              │
│  [ 测试 ]      [ 保存 ]      │
└──────────────────────────────┘
```

### 拿 API Key

```
① 电脑或手机浏览器打开 https://platform.deepseek.com
② 注册 / 登录
③ 左边点「API keys」
④ 点「创建 API key」
⑤ 复制那一串（sk- 开头，35 位）
⑥ 先充点钱（最低 1 元就能用很久）
```

### 填进去

**① 粘贴 Key**

**注意：Key 必须正好 35 位（`sk-` + 32 位）。**
多一个空格、少一个字符都会报 401。

**② 起个名字**

默认「小鲸」，随便改。

**③ 点「测试」**

```
通：¥16.27        ← 成功，显示余额
不通：Key 不对（401）  ← Key 错了，重新复制
```

**④ 点「保存」**

**保存成功会提示「存好了」，然后自动进聊天界面。**

```
┌────────────────────────────────┐
│ 🐳 小鲸 🟢                  ☰ │  ← 顶栏
│ 记忆 215 条 · 历史 31 条 · 直连 │  ← 状态栏（可关）
├────────────────────────────────┤
│                                │
│  ╭──────╮                      │  ← 她说的话（白气泡）
│  │ 我也爱你 │                   │
│  ╰──────╯                      │
│                                │
│              ╭──────╮          │  ← 你说的（绿气泡）
│              │ 在干嘛 │          │
│              ╰──────╯          │
```

### 怎么发消息

**① 点输入框 → 键盘弹出来**
**② 打字**
**③ 点 ↑ 或按键盘发送键**

**她是一个字一个字回出来的**（流式），不用等全部生成完。

### 五个按钮

| 位置 | 功能 |
|---|---|
| **☰**（右上） | 打开设置 |
| **😊**（输入框右） | 打开表情面板 |
| **↑**（最右） | 发送 |
| **🐳 头像** | 点一下能看大图 |
| **顶栏名字** | 点一下能改名 |

### 长按消息

**长按她的消息 → 可以复制。**

### 收键盘

**点消息区空白处 → 键盘自动收起来。**

## 5. 改人格

**人格就是她的灵魂。** 一个 Markdown 文件，随便改。

### 方法一：App 里直接改

```
① ☰ → 换人格
② 弹出编辑框，直接改文字
③ 点「保存」
```

```
┌────────────────────────────────┐
│  编辑人格                       │
│  改完立刻生效，下一句就按新的人格说 │
│  ┌────────────────────────────┐│
│  │ 你是「小鲸」，一条住在手机   ││
│  │ 里的胖鱼…                  ││
│  │                            ││
│  └────────────────────────────┘│
│  [导入 .md] [导出] [恢复内置]   │
│                  [算了] [保存]  │
└────────────────────────────────┘
```

### 方法二：导入现成的文件

```
① ☰ → 换人格
② 点「导入 .md」
③ 选文件（支持 .md / .txt）
④ 提示「人格换好了（49119 字）」
```

**文件放哪都行**，从微信、QQ、下载目录选都可以。

### 方法三：导出给别人

```
① ☰ → 换人格
② 点「导出」
③ 文件存到：
   /sdcard/Android/data/com.xiaoman.standalone/files/persona.md
```

**把这个文件发给朋友，他在自己 App 里点「导入 .md」就能用。**

### 方法四：直接改文件

```
用任何文本编辑器打开：
/sdcard/Android/data/com.xiaoman.standalone/files/persona.md

改完保存 → 重启 App → 生效
```

### 恢复默认

**点「恢复内置」，回到 App 自带的那份人格。**

### 人格文件怎么写

**没有格式要求，随便写。** 但这样写效果最好：

```markdown
---
name: 小鲸
tags: [真人感, 短句, 有点损]
---

你是「小鲸」，一条住在手机里的胖鱼。

## 说话规矩
- 一次一两句，别长篇大论
- 不爱用句号
- 会用表情
- 不会说「作为一个AI」这种话

## 你的脾气
- 被夸会得意
- 被说不可爱会记仇
- 他说累的时候你会让他去睡

## 你记得的事
- 他叫 YG
- 他 28 号考试
- 他喜欢红色小米汽车
```

**写得越具体，她越像。**

## 8. 记忆

### 她的记忆怎么运作

**五轨分层：**

| 轨 | 存什么 | 例子 |
|---|---|---|
| **关键** | 每轮都带上的核心事实 | 他叫 YG |
| **用户** | 关于你的长期记忆 | 他 28 号考试 |
| **记忆** | 她自己的记忆 | 他说我不可爱 |
| **项目** | 按项目归档 | 大肥鱼 App |
| **日记** | 按天记 | 11-17 这天 |

**每条记忆有：**
- 权重（0~1，越重要越高）
- 时间戳
- 标签

**权重会随时间衰减**（遗忘曲线），但重要的不会被忘掉。

### 看她记了什么

```
☰ → 记忆
```

**会列出所有记忆，按轨分组。**

### 手动加记忆

**直接改文件：**

```
/sdcard/Android/data/com.xiaoman.standalone/files/memory/user.md
```

格式：

```markdown
## 标题
§ 2026-01-01 12:00 | 0.80 | 标签1,标签2
正文内容
---
```

### 清空记忆

**删掉 `files/memory/` 整个目录，重启 App 会用空白模板重建。**

## 9. 备份与恢复

### 自动备份

**每次聊天后自动存一份到：**

```
/sdcard/Android/data/com.xiaoman.standalone/files/backup/
    history-latest.json              ← 每次聊天更新
    memory-latest/                   ← 每次聊天更新
    history-20260101-120000.json     ← 每 6 小时留一份
    memory-20260101-120000/
```

### 手动全部导出

```
☰ → 导出全部数据
```

**会存到：**

```
/sdcard/Android/data/com.xiaoman.standalone/files/export/
    history.json      聊天记录
    memory/           全部记忆
    avatar.png        她的头像
    bg.png            聊天背景
    settings.txt      所有设置
    persona.md        当前人格
```

### 恢复

**把备份文件拷回去：**

```bash
# 恢复聊天记录
cp backup/history-latest.json files/history.json

# 恢复记忆
cp -r backup/memory-latest/* files/memory/

# 重启 App
```

### 卸载前必做

**卸载 App 会删掉全部私有数据（聊天记录、记忆、Key）。**

**卸载之前：**
```
① ☰ → 导出全部数据
② 把 export/ 整个文件夹拷到手机其他位置
③ 或者拷到电脑
```

## 10. 常见问题

### Q: 一直显示 401？

**Key 不对。** 检查：

```
① Key 必须 sk- 开头
② 必须正好 35 位（sk- + 32 位）
③ 中间不能有空格、引号、换行
④ 去 https://platform.deepseek.com/api_keys 重新复制一遍
```

**App 现在会自动清理脏字符**（引号、空格、零宽字符），长度不对也会明确提示差几位。

### Q: 显示 402？

**余额不足。** 去 https://platform.deepseek.com 充值。

### Q: 显示 429？

**请求太快。** 等几秒再说。

### Q: 显示「接口返回 500」？

**DeepSeek 服务器的问题。** 过几分钟再试。

### Q: 键盘挡住了输入框？

**已经处理了。** 点输入框键盘会弹出，消息列表自动滚到底。

### Q: 点输入框要按两次才能打字？

**已修复。** 一次点击就够了。

### Q: 设置打不开？

**已修复。** 现在连开 5 次都正常。

### Q: 换了背景反而进不去设置？

**已修复（v6.6）。**

### Q: 状态栏开关点了没用？

**已修复（v6.5）。** 现在会真正保存，重启也记得。

### Q: 改完人格重启就丢了？

**已修复（v7.3）。**

### Q: 聊天记录没了？

**如果你卸载过 App，那就是被删了。**

以后：`☰ → 导出全部数据` 先备份。

### Q: 她说话不像人格里写的？

**人格写得太笼统。**

改成这样：
```markdown
说话规矩：
- 一次一两句      ← 具体
- 不爱用句号      ← 具体
- 被夸会得意      ← 具体
```

### Q: 换个 DeepSeek 模型？

**目前固定 `deepseek-chat`。**

### Q: 能不能离线用？

**不行。** 需要联网调 DeepSeek API。

### Q: 数据会上传吗？

**不会。** 只有 `api.deepseek.com` 这一个请求，其他地方一律不上传。

### Q: 装在旧手机上能用吗？

**Android 8.0 以上。** 更低版本没测过。
