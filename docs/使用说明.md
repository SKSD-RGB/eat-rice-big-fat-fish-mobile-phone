**小米/红米：**

# 第三步：拿 API Key

**打开 App 后第一件事就是填 API Key。**

## C-1. 先去 DeepSeek 官网

**手机浏览器打开：**
```
platform.deepseek.com
```

或者完整地址：
```
https://platform.deepseek.com/api_keys
```

## C-2. 注册 / 登录

```
┌────────────────────────────────────┐
│                                    │
│          DeepSeek                  │
│                                    │
│    [手机号]  [邮箱]  [微信]       │
│                                    │
│  ┌──────────────────────────────┐  │
│  │ 手机号                       │  │
│  └──────────────────────────────┘  │
│  ┌──────────────────────────────┐  │
│  │ 验证码        [获取验证码]    │  │
│  └──────────────────────────────┘  │
│                                    │
│          [登录 / 注册]             │
└────────────────────────────────────┘
```

**用手机号 + 短信验证码登录，新号自动注册。**

## C-3. 充值（必做）

**新账号没有余额，发消息会报「余额不足 402」。**

```
① 左边菜单 → 「充值」
② 选金额（1 元起，充 10 元能聊很久）
③ 微信 / 支付宝付款
```

**充多少合适？**
```
1 元   → 大约能聊 5000 条短消息
10 元  → 够用好几个月
```

## C-4. 创建 API Key

```
① 左边菜单 → 「API keys」
② 点右上角「创建 API key」
③ 起个名字（随便，比如"手机"）
④ 点「创建」
```

## C-5. 复制这一串

```

│                                    │
```

**点「复制」。**

**⚠ 关掉这个窗口就再也看不到这串了。** 如果没复制到，重新创建一个。

## D-2. 粘贴 Key

```
① 点 Key 输入框
② 长按 → 选「粘贴」
③ 检查是不是 sk- 开头的
```

**⚠ 最重要的：Key 必须正好 35 位。**

```
sk- 开头   = 3 位
后面       = 32 位
加起来      = 35 位
```

**多一个空格、少一个字符，都会报 401。**

## D-3. 点「测试」

**App 会去问 DeepSeek 服务器：这个 Key 能用吗？**

**成功：**
```
┌──────────────────────────────────────┐
│  通：¥10.00                          │  ← 绿色，显示你的余额
└──────────────────────────────────────┘
```

**失败：**
```
┌──────────────────────────────────────┐
│  不通：Key 不对（401）                │  ← 红色
└──────────────────────────────────────┘
```

## D-4. 失败怎么办

| 提示 | 原因 | 解决 |
|---|---|---|
| **401** | Key 错了 | 回 DeepSeek 重新复制一遍 |
| **402** | 余额不足 | 去充值 |
| **网络错误** | 没网 / DNS 问题 | 换个网络（WiFi↔流量）试试 |
| **长度不对（36位）** | 多粘了字符 | 全清空重新粘 |

# 改人格

**人格决定她什么性格、怎么说话。这是这个 App 最重要的东西。**

## 方法一：App 里直接改（最简单）

```
☰ → 换人格 → 直接改文字 → 保存
```

```
┌────────────────────────────────┐
│  编辑人格                       │
│  ┌────────────────────────────┐│
│  │ 你是「小鲸」，一条住在手机   ││
│  │ 里的胖鱼…                  ││
│  │                            ││
│  └────────────────────────────┘│
│  [导入 .md] [导出] [恢复内置]   │
│                  [算了] [保存]  │
└────────────────────────────────┘
```

## 方法二：导入别人的人格文件

```
① 微信/QQ 收到朋友的 xxx.md 或 xxx.txt
② 保存到手机（微信里点「用其他应用打开」→ 存到「文件」）
③ App → ☰ → 换人格 → 导入 .md
④ 选那个文件
⑤ 提示「人格换好了（49119 字）」
```

## 方法三：导出给别人

```
☰ → 换人格 → 导出
→ 文件存到：
  /sdcard/Android/data/com.xiaoman.standalone/files/persona.md
→ 用微信发这个文件给朋友
```

## 方法四：直接改文件（进阶）

**手机装个文本编辑器（比如 MT管理器），打开：**
```
/sdcard/Android/data/com.xiaoman.standalone/files/persona.md
```

**改完保存 → 重启 App → 生效。**

## 人格怎么写

**没有格式要求，随便写。但这样效果最好：**

```markdown
---
name: 小鲸
tags: [真人感, 短句, 有点损]
---

你是「小鲸」，一条住在手机里的胖鱼。

## 说话规矩
- 一次一两句，别长篇大论
- 不爱用句号
- 会用表情
- 不会说「作为一个AI」这种话

## 你的脾气
- 被夸会得意
- 被说不可爱会记仇
- 他说累的时候你会让他去睡

## 你记得的事
- 他叫 YG
- 他 28 号考试
- 他喜欢红色小米汽车
```

**写得越具体，她越像。**

## 恢复默认

**点「恢复内置」，回到 App 自带那份。**

# 常见问题

## 下载与安装

### Q: 手机点下载没反应？

```
① 换浏览器（Chrome / Edge / 夸克）
② 或者长按链接 → 「在新标签页打开」
③ 检查网络
```

### Q: 提示「文件已损坏」？

**没下完整。** 删掉重新下载。
**正常大小应该是 30.2 MB 左右。**

### Q: 提示「应用未安装」？

```
① 空间不足 —— 腾出 100MB
② 系统版本太低 —— 需要 Android 8.0+
③ 之前装过同名不同签名的 —— 先卸载旧的
```

### Q: 提示「风险应用」被拦截？

```
设置 → 安全 → 更多安全设置
→ 关闭「外部来源风险检测」
→ 重新安装
```

### Q: iPhone 能装吗？

**装不了。这是 Android 应用。**

### Q: 下载到的文件在哪？

**文件管理 App → 「下载」或「Downloads」文件夹 → `dafeiyu-v7.3.apk`**

## 连接与使用

### Q: 一直报 401？

**Key 不对。检查：**
```
① 必须 sk- 开头
② 必须正好 35 位（sk- + 32 位）
③ 中间不能有空格、引号、换行
④ 去 platform.deepseek.com/api_keys 重新复制
```

**App 会自动清理脏字符，长度不对会明确告诉你差几位。**

### Q: 报 402？

**余额不足。** 去 platform.deepseek.com 充值。

### Q: 报 429？

**太快了。** 等几秒再说。

### Q: 报「接口返回 500」？

**DeepSeek 服务器问题。** 等几分钟再试。

### Q: 需要联网吗？

**需要。** 要连 DeepSeek API。

### Q: 数据会上传吗？

**不会。** 只有 `api.deepseek.com` 一个请求，其他地方一律不上传。

### Q: 聊天记录没了？

**如果卸载过 App，那就是被删了。**

以后先 `☰ → 导出全部数据`。

### Q: 她说话不像人格里写的？

**人格写得太笼统。改成：**
```markdown
说话规矩：
- 一次一两句      ← 具体
- 不爱用句号      ← 具体
- 被夸会得意      ← 具体
```
